Settings and shortcuts

Open Settings with Ctrl+, or from the command palette.

SettingWhat it does
ThemeLight, dark, or follow the system.
Commit graphTimeline (two lines per commit) or compact rows.
ZoomScales the whole app, from 80% to 150%.
Git executableWhich git to use. Leave it empty to find it on your PATH. A change takes effect after a restart.
Clone intoWhere new clones go. Empty means the folder of the last repository you opened.
UpdatesWhether to check GitHub for a newer version at startup. This is the only request the app makes on its own.

With a repository's tab active, a This repository section adds settings that belong to it:

SettingWhat it does
Trunk, Release, Environment, Docs, Feature, BotThe patterns that decide each branch kind. Use defaults puts one back.
Clean up merged branches after each pullDeletes local branches whose upstream was deleted and that have nothing unpushed. More.
Sync notes on fetch, pull and pushShares git notes with the remote. More.
Hidden branchesPatterns of branches to leave out of the sidebar and graph. More.

Settings are saved to settings.json; see where your data lives. Git's own settings, such as your name, email and aliases, are edited in the Git Config tab: choose Edit git config… under Git.

The command palette​

Ctrl+K opens the command palette: every command in the app, searchable, with its shortcut if it has one. Type a few letters of what you want and press Enter.

In the sidebar's list, the keys are different: see the commit graph.

Changing them​

Choose Customize keyboard shortcuts… from the command palette or Settings. Every command in the palette is listed, with its keys. Record new keys for any of them, including commands that have none yet. Changes are saved as you make them.
